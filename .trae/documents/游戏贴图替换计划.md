## 实现方案

### 方案A：使用Data URI（推荐）
1. 下载PNG图片
2. 转换为Base64 Data URI
3. 直接嵌入JavaScript代码
4. 优点：无需外部服务器

### 方案B：下载到本地
1. 下载PNG到 `public/sprites/` 目录
2. 修改服务器提供静态文件
3. 优点：图片质量更高，调试方便

## 具体实施步骤

### 第一步：创建贴图数据结构
在 `game.js` 中创建贴图对象：
```javascript
this.sprites = {
    weapons: {
        pistol: 'data:image/png;base64,...',
        shotgun: 'data:image/png;base64,...',
        smg: 'data:image/png;base64,...',
        rifle: 'data:image/png;base64,...',
        sniper: 'data:image/png;base64,...',
        rocket: 'data:image/png;base64,...'
    },
    vehicles: {
        tank: 'data:image/png;base64,...',
        armored: 'data:image/png;base64,...',
        helicopter: 'data:image/png;base64,...'
    }
};
```

### 第二步：修改绘制函数
- `drawPlayer()` - 绘制玩家
- `drawEnemies()` - 绘制敌人
- `drawVehicles()` - 绘制载具
- `drawBullets()` - 绘制子弹

### 第三步：替换武器栏图标
- 将emoji (🔫🔥💥🎯▬▮◉) 替换为小尺寸贴图

### 第四步：加载预载
- 使用 `Image()` 对象预加载所有贴图
- 确保贴图加载完成后再开始游戏

1. 选择透明背景PNG
2. 统一图片尺寸（如 64x64 或 128x128）
3. 确保贴图风格一致
4. 优化Base64编码减少文件大小
