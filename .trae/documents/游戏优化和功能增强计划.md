# 游戏优化和功能增强计划

## 问题诊断

### 1. 卡顿问题
- **原因**：粒子效果过多、敌人生成太频繁、更新频率过高
- **解决方案**：
  - 减少粒子最大数量（300→150）
  - 减少敌人生成频率（2秒→3秒）
  - 优化渲染逻辑，减少不必要的绘制

### 2. 联机时人不见了
- **原因**：玩家数据同步问题、网络延迟、玩家死亡后未正确重生
- **解决方案**：
  - 修复玩家死亡重生逻辑
  - 优化网络同步机制
  - 添加玩家断线重连处理

### 3. 载具系统
- **实现方式**：
  - 载具类型：坦克（高伤害慢速）、装甲车（中等）、直升机（快速）
  - 玩家可以进入/离开载具
  - 载具拥有独立的生命值和武器
  - 使用简单的几何图形绘制载具（避免外部图片依赖）

### 4. 道具系统
- **道具类型**：
  - 生命恢复道具
  - 弹药补给
  - 护盾道具（临时无敌）
  - 加速道具
  - 隐形道具
- **实现**：在地上生成可拾取的道具，靠近自动拾取

### 5. 枪械系统增强
- 添加更多武器类型
- 每种武器有不同的射速、伤害、弹药数
- 武器可以在地上掉落或从商店购买

## 具体实现步骤

### 第一步：性能优化
1. 修改 `game.js` 中的性能参数
   - `maxParticles`: 150
   - `maxEnemies`: 6
   - `spawnInterval`: 3000ms
2. 添加对象池复用子弹和粒子

### 第二步：载具系统
1. 在 `game.js` 中添加载具类
   ```javascript
   class Vehicle {
       constructor(type, x, y)
       update()
       draw()
       enter(player)
       exit()
   }
   ```
2. 载具类型定义：
   - 坦克：半径40，速度2，伤害40
   - 装甲车：半径35，速度4，伤害20
   - 直升机：半径30，速度6，伤害15
3. 添加载具生成逻辑
4. 实现进入/退出载具功能

### 第三步：道具系统
1. 添加道具数组
2. 随机在地图上生成道具
3. 玩家靠近自动拾取
4. 实现各种道具效果

### 第四步：枪械系统
1. 添加新武器：
   - 步枪：均衡属性
   - 机枪：高射速，低伤害
   - 火箭筒：高伤害，低射速
2. 武器可以通过击杀敌人概率掉落

### 第五步：网络优化
1. 修复玩家同步问题
2. 确保玩家死亡后正确重置状态
3. 优化数据传输频率
